# 🎮 BLOC1.PT3 - Gestió d'excepcions

## 📌 Descripció
Aquest projecte consisteix a treballar la gestió d'excepcions en C# mitjançant els blocs `try`, `catch` i `finally`.

## 📚 Exercicis

### 1. 🧪 Comprar pocions (Try/Catch)
- Demanar a l'usuari quantes pocions vol comprar.
- Convertir l'entrada utilitzant `int.Parse()`.
- Gestionar les excepcions `FormatException` i `OverflowException`.
- Repetir la pregunta fins que l'entrada sigui correcta.

### 2. 💰 Repartir el botí (Catch)
- Demanar la quantitat total d'or i el nombre de membres del grup.
- Calcular quants diners rep cada membre.
- Gestionar les excepcions `FormatException`, `DivideByZeroException` i les excepcions inesperades mitjançant `Exception`.

### 3. 🗺️ Mapa de la masmorra - Matriu (Finally)
- Crear una matriu de tipus `string[,]` de 3x3 que representi el mapa d'una masmorra.
- Demanar a l'usuari una fila i una columna.
- Mostrar la sala seleccionada.
- Gestionar les excepcions `FormatException` i `IndexOutOfRangeException`.
- Utilitzar `finally` per mostrar un missatge quan finalitza la consulta del mapa.

### 4. 🧰 Mapa de la masmorra - Jagged Array (Finally)
- Crear un jagged array (`int[][]`) que representi cofres amb diferents quantitats d'objectes.
- Demanar a l'usuari que seleccioni un cofre i un objecte.
- Mostrar l'objecte seleccionat.
- Gestionar les excepcions `FormatException` i `IndexOutOfRangeException`.
- Utilitzar `finally` per indicar el final de la consulta del cofre.
